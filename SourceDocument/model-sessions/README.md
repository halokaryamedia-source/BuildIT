# Session Storage Redirection

The source-of-truth runtime session folders for active assets are now kept under:

- `SavedData/sessions/<asset_name>/`

Use this folder only as a documentation index and compatibility map.

Current convention:
- `session.md`: status, phase contract, and handoff notes
- `session-lock.md`: active lock and MCP scope control
- `references/`: generated/selected reference packs used in the session
- `phase-screenshots/` and `final-screenshots/`: optional review captures

Current active model references:
- `SavedData/sessions/kangaroo/`
