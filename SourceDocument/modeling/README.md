# Modelling Workflow Index

This folder controls the full Bedrock Entity modelling flow from asset brief to final review.

## Core Flow

1. Brief Asset
   - Use `minecraft-model-brief-template.md`.
   - Lock target object, function, size, style, animation need, UV atlas target, and texture style.

2. Reference Package
   - Use `../reference-templates/`.
   - Visual references may be generated by ChatGPT/GPT image, Codex image tools, API tools, or supplied manually by the user.
   - The generator does not matter; the output must pass the same notes, manifest, handoff, and reference gates.
   - If the source image is not Minecraft style, fill `minecraft-style-image-conversion-preflight.md`, then apply `minecraft-style-image-conversion-rules.md` and the full `minecraft-style-image-conversion-mandatory-prompt.md` before generating Sheet 01.
   - Follow the approved 8-sheet structure:
     1. Shape / orthographic views
     2. Scale
     3. Silhouette
     4. Part breakdown
     5. Color / texture
     6. Close-up detail
     7. Execution target
     8. Pivot optional

3. Reference Gate
   - Use `reference-package-pass-fail-checklist.md`.
   - Confirm all sheets, notes, manifest, handoff, and geometry-vs-texture rules are aligned.
   - User must approve the reference package.

4. Pre-Modelling Gate
   - Use `pre-modelling-gate.md`.
   - Confirm scale, front direction, geometry parts, texture-only parts, atlas, texture style, and Main Geometry scope.

5. Main Geometry
   - Use `mandatory-blockbench-mcp-procedure.md`, `phase-detail-contract.md`, and `modeling-phase-quality-playbook.md`.
   - Build only scale, silhouette, large part groups, parent structure, and placeholder colors.

6. Geometry Detailing
   - Add only geometry that improves structure or silhouette.
   - Keep seams, pixels, trim, scratches, and color bands for texture.

7. UV Texture
   - Use `texture-uv-rules.md`.
   - Set atlas and per-face UV logic before painting.

8. Base Texturing
   - Use Sheet 05 and `minecraft-style-rules.md`.
   - Place broad material zones and main colors first.

9. Detail Texturing
   - Add pixel detail, trim, stepped shading, and accents.
   - Do not add geometry for texture-only detail.

10. Polish
   - Use `visual-qa-checklist.md` and `phase-quality-scorecard-template.md`.
   - Only small fixes unless an earlier phase is reopened.

11. Final Review
   - Compare final model against every approved reference sheet.
   - Stop if scale, silhouette, part groups, palette, or pivot assumptions drift.

## Reference Generator Tools

Use the best available tool for the visual task:

- ChatGPT/GPT image is preferred when strict image-to-Minecraft style conversion is needed.
- Codex may still create notes, manifests, handoff files, validation, and simple deterministic drafts.
- Any generated visual must still follow the same 8-sheet package structure and gates.
