# Visual QA Checklist

Use this checklist before accepting a modelling workflow as done.

## Views

- [ ] Front view is readable.
- [ ] Side view is readable.
- [ ] Back view is readable.
- [ ] Top view is readable.
- [ ] Perspective view is readable.

## Minecraft Readability

- [ ] Asset silhouette is clear from gameplay distance.
- [ ] Main forms follow Minecraft / Blockbench style expectations.
- [ ] Geometry does not rely on generic smooth 3D assumptions.
- [ ] Small details are represented with texture where appropriate.

## Texture and UV

- [ ] Texture clarity is acceptable.
- [ ] UVs are not visibly stretched.
- [ ] Pixel density is consistent.
- [ ] Texture names are final enough for export.

## Rigging, Pivot, and Export

- [ ] Pivot and bone placement are correct for the asset type.
- [ ] Required animations are present or marked `Out of scope`.
- [ ] Export format matches the target platform.
- [ ] Model, texture, and animation outputs are present when required.
- [ ] Known limitations are documented.

## Acceptance Criteria

- All required views are checked.
- Minecraft style consistency is checked.
- Texture, UV, pivot, bone, and export checks are completed.
- Failed checks are corrected or documented as approved exceptions.
