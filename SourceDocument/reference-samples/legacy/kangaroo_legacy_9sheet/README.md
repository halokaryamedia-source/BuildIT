# Kangaroo Reference Package Sample

This folder is a sample reference package for ChatGPT and Codex planning.

Important:

- These images are examples of the desired reference-sheet structure.
- Do not treat kangaroo as the required target model.
- Do not copy the kangaroo design unless the user explicitly asks for a kangaroo.
- Use this package to understand file naming, sheet order, layout clarity, and planning depth.

Required sample order:

```text
01_kangaroo_orthographic_views.png
02_kangaroo_scale_sheet.png
03_kangaroo_silhouette_sheet.png
04_kangaroo_part_breakdown_sheet.png
05_kangaroo_color_palette_sheet.png
06_kangaroo_texture_reference_32x32.png
07_kangaroo_closeup_detail_sheet.png
08_kangaroo_do_dont_sheet.png
09_kangaroo_animation_pivot_sheet_optional.png
```

Use the same structure for future assets:

```text
01_[asset]_orthographic_views.png
02_[asset]_scale_sheet.png
03_[asset]_silhouette_sheet.png
04_[asset]_part_breakdown_sheet.png
05_[asset]_color_palette_sheet.png
06_[asset]_texture_reference_[atlas_size].png
07_[asset]_closeup_detail_sheet.png
08_[asset]_do_dont_sheet.png
09_[asset]_animation_pivot_sheet_optional.png
```

## Acceptance Criteria

- ChatGPT uses these images as format examples only.
- ChatGPT asks what new asset should be created before generating references.
- Future reference packages follow the same naming and sheet order.
