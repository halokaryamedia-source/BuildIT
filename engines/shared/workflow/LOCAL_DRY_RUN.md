# Local Dry Run

Run after the Rework plugin is built and loaded in one Blockbench window.

Prove:

1. canonical connection and one write session;
2. exact tool profile exposure and one reconnect per stage transition;
3. one-time package/project preflight;
4. Geometry review and targeted revision;
5. Texture review and targeted revision;
6. Animation review or clean skip;
7. Final Validation and final review;
8. persistent checkpoints and stable evidence paths.

Record only actionable waste: repeated reads, unnecessary calls, oversized payloads, duplicate screenshots, ambiguous state, or manual steps repeated enough to justify automation. CI does not replace this proof.
