# Codex Integration

Codex-specific authority is limited to connection, bootstrap, and local helper scripts.

- `BOOTSTRAP.md`: normal production entry point.
- `CONNECTION_CONTRACT.md`: canonical Blockbench MCP connection.
- `connection-profile.json`: machine-readable connection contract.
- `scripts/`: deterministic connection and profile helpers.

Shared stage behavior belongs in `../shared/`, not here.
