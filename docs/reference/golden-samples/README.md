# BuildIT Golden Samples

Golden Samples are complete, approved reference packages used for runtime calibration and end-to-end validation.

## Available sample

```text
black_rhinoceros
```

Documentation:

```text
docs/reference/golden-samples/black_rhinoceros/
```

Binary package:

```text
black_rhinoceros_blockbench_reference.zip
```

The binary ZIP contains the four PNG sheets and the same approved Markdown/JSON contracts. Codex must use the extracted ZIP package for runtime production; loose Markdown files alone are documentation and are not a valid asset package.

When the package is present locally, the expected root is:

```text
black_rhinoceros_blockbench_reference/
```

The package is identified by `sample_type: golden_sample` and `asset_id: black_rhinoceros`.
