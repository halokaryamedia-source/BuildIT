# Black Rhinoceros Golden Sample

This directory documents the approved BuildIT Golden Sample.

The full runtime package is distributed as:

```text
black_rhinoceros_blockbench_reference.zip
```

It contains:

- Sheet 01 form and scale reference;
- Sheet 02 construction reference;
- Sheet 03 texture and material reference;
- Sheet 04 pivot-readiness reference;
- Production Context;
- Geometry, Texture, Animation, and Validation contracts;
- reference manifest with hashes;
- Codex handoff;
- package audit.

The Markdown and JSON files in this directory are committed so Codex and maintainers can understand the authority, scale, hierarchy, UV plan, animation-skip decision, and expected runtime flow.

For actual model generation, extract the full ZIP so the PNG authorities are present.
