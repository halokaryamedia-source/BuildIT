Status: `APPROVED`
Package Type: `blockbench_reference`
Sample Type: `golden_sample`

## Purpose

This package is the canonical BuildIT Golden Sample used to validate the boundary between:

```text
ChatGPT Reference Studio
→ approved reference package
→ Codex import
→ MCP-Blockbench Geometry and Texture production
→ Final Validation
```

It is intentionally small enough to test reliably while still covering:

- organic cuboid construction;
- nontrivial hierarchy;
- large-scale proportions;
- horns, ears, feet, and tail attachments;
- Classic Bedrock texture planning;
- stage review evidence;
- checkpoint integrity;
- final validation.

## Approved scope

- Geometry: required
- Texture: required
- Animation: skipped
- Final Validation: required

## Selection rule

Codex may select this package automatically when the user requests the BuildIT Golden Sample or when runtime validation requires a complete approved sample and no other Golden Sample is selected.

Codex must not use loose images as substitutes for this package.

A recognizable Minecraft-style black rhinoceros with:

- `2.5-block` approved height;
- heavy shoulder and torso masses;
- a low broad head;
- two horns;
- four grounded legs;
- low-contrast gray-brown hide;
- no animation clips.
