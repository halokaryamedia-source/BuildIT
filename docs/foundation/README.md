# BlockIT Foundation

This folder is the product and operating-model source of truth.

## Document Groups

### Policy and Product

- `00-agent-policy.md`: operating rules and source precedence.
- `01-project-overview.md`: product purpose and boundaries.
- `02-product-requirements.md`: required product behavior and quality.

### Workflow

- `03-modelling-workflow.md`: end-to-end modelling sequence.
- `04-reference-guide.md`: reference input requirements.
- `08-source-selection.md`: source and reference selection rules.
- `09-merge-map.md`: source and repository merge boundaries.

### Modelling Standards

- `05-geometry-standard.md`: geometry and proportion rules.
- `06-texture-standard.md`: texture rules.
- `07-visual-validation.md`: visual acceptance and quality gates.

### Verification

- `validation-report.md`: verified findings and remaining `Needs Validation`
  items.

## Recommended Read Order

1. Read `00-agent-policy.md` and `01-project-overview.md` for context.
2. Read `02-product-requirements.md` for product scope.
3. Read the relevant workflow or modelling-standard document.
4. Read `validation-report.md` when proof status matters.

## Rule of Use

- Use these docs for verified product rules, workflow order, and acceptance.
- Keep working notes out of this folder unless they become stable policy.
- If a rule is unverified, mark it `Needs Validation`.

## Bridge to Knowledge

- Use `docs/knowledge/index.md` for workflow notes, decisions, and module maps.
- Use `docs/knowledge/glossary.md` to keep terms stable across notes.
- Use `docs/knowledge/decisions/` when a choice needs a permanent record.
- Use `docs/knowledge/operations/` for active work that should not yet become policy.
