**Status:** test-support contract; not a navigation owner. Human-facing detailed flow: `docs/knowledge/flow.md`.

## Minimum Necessary Evidence

Use the smallest evidence that can change the next modelling decision. `UNVERIFIED` is an evidence state, not a command to create more calls.

- no per-Cube inspect by default;
- no screenshot-per-mutation loop;
- bounds are conditional on an envelope/scale/ground/displacement question;
- successful mutation is execution evidence, not visual approval;
- primary-form failure returns upstream before texture or animation;
- keyframe effort never justifies preserving a bad rig or geometry baseline.

This file exists only to keep long-lived regression assertions stable while the active workflow remains single-owned by `docs/knowledge/flow.md`.
