# Roadmap

Current focus for the knowledge vault:

1. Keep the vault easy to enter from Obsidian.
2. Keep `docs/foundation/` clean and stable.
3. Keep `docs/knowledge/` practical and modular.
4. Track active ownership for runtime and skill areas.
5. Turn repeated work into decisions, templates, or maintenance notes.

## Next Obvious Improvements

- add more real notes only when a module or workflow is actually active;
- promote repeated operation patterns into a stable template or decision record;
- keep the dashboard short enough that a new session can start from it immediately;
- move any proven working rule from knowledge into foundation when it becomes policy.
