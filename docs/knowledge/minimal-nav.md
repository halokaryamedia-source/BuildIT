# Minimal Navigation

Use this as the single boot navigation index when a task starts.

## Start

1. `AGENTS.md` — agent rules are loaded by the workspace.
2. Root [`CONTEXT.md`](../../CONTEXT.md) — stable facts.
3. [Next Action](next-action.md) — one active task.
4. [Workspace Map](workspace-map.md) — identify the affected area.

## Then

- Open [Foundation README](../foundation/README.md) only for product or
  modelling rules.
- Open [Activation Matrix](skills/activation-matrix.md) only when selecting a
  workflow or skill.
- Open the matching module/source index only after identifying the task area.

## Stop Rule

- If the answer is not in the boot context, open one relevant source next.
- Do not broad-scan the vault, archive, generated output, or dependencies by
  default.
