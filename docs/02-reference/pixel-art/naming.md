# Pixel Art Naming

Use existing project naming conventions when available.

Otherwise prefer concise lowercase snake_case for working asset identities.

Examples:

```text
fishing_rod
parking_icon
fuel_bottle_blue
cyberpunk_kiosk
cat_walk_01
```

For series, keep one base identity and semantic suffixes. Avoid revision-history suffixes in production names when a clean final identity is available.

Naming does not define style or runtime ownership.
