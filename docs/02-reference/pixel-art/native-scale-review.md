# Pixel Art Native-Scale Review

Pixel art must be reviewed at the size at which it is expected to function.

## Two-view review

Use both:

```text
100% target scale
→ semantic/readability judgment

integer nearest-neighbor enlargement
→ grid/cluster/edge inspection
```

## Native-scale questions

- Is the subject immediately recognizable?
- Are identity landmarks visible?
- Is value separation sufficient?
- Does important detail survive?
- Does any noise merge into unintended texture?
- Does the asset feel balanced inside its canvas?

## Enlarged-view questions

- Are staircases intentional?
- Are orphan pixels justified?
- Are alpha edges clean?
- Are cluster shapes coherent?
- Is visible pixel scale consistent?

Do not approve an asset solely because the enlarged preview looks detailed.
