# Pixel Art Production Checklist

Use only as a final compact reminder; detailed ownership remains in the relevant technical files.

```text
[ ] artifact class resolved
[ ] target mode resolved
[ ] canvas/grid justified
[ ] subject readable at native size
[ ] silhouette stable
[ ] pixel scale coherent
[ ] clusters deliberate
[ ] palette economical
[ ] materials readable when applicable
[ ] identity landmarks preserved
[ ] style lock respected for series work
[ ] animation consistency checked when applicable
[ ] repeat seam checked for tiles when applicable
[ ] alpha/background clean
[ ] applicable qa.md gates passed
[ ] downstream handoff contains only required state
```

Do not treat checklist completion as evidence when visual review contradicts it.
