# Pixel Art Object / Prop

## Purpose

Author compact standalone representations of real or designed objects while preserving function, material, and identity.

## Priority order

```text
functional silhouette
→ proportion hierarchy
→ defining components
→ material grouping
→ color identity
→ secondary detail
```

## Functional features

Preserve the parts that explain what the object does:

- handles;
- blades;
- lenses;
- openings;
- containers;
- screens;
- wheels;
- hinges;
- nozzles;
- straps.

At low resolution these may be selectively exaggerated for recognition.

## Multi-material objects

Separate materials by value and cluster behavior before relying on hue differences.

Example: a fuel bottle should read as container + liquid, not as one blue solid shape.

## Proportion simplification

Simplification may compress thin parts or enlarge critical features, but should retain the subject's overall width/height and component relationship.

## Minecraft-facing props

For Minecraft-oriented assets, retain blocky clarity and restrained detail without forcing every object into a cube silhouette.

## Review

At target scale ask:

1. Is the object category clear?
2. Is its primary function clear?
3. Are major materials separable?
4. Are defining components preserved?
5. Does any detail exist only because the canvas is enlarged?
