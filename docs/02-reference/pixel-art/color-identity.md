# Pixel Art Color Identity

## Purpose

Preserve subject-specific color identity without allowing color to replace form readability.

## Rule

Identity color is subordinate to silhouette and value structure but should be preserved when it is a defining subject cue.

Examples include:

- brand/functional accent;
- distinctive liquid color;
- team/faction marker;
- warning color;
- characteristic material finish.

## Value safety

Two identity colors that collapse to the same value may require outline, spacing, or controlled value adjustment so their boundary remains readable.

## Reference work

Distinguish between:

```text
REFERENCE-SUPPORTED color
STYLE-LOCK color
PROVISIONAL interpretation
```

Do not claim a provisional shade is reference-accurate.
