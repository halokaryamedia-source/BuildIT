# Pixel Art UI Symbols

Use for abstract or typographic symbols such as parking markers, arrows, status icons, and simple GUI glyphs.

## Priority

```text
semantic clarity
→ geometric balance
→ native-size readability
→ set consistency
→ decoration
```

## Geometry

Prefer clean integer-grid geometry. Optical correction is allowed when mathematically centered shapes look visually unbalanced at low resolution.

## Typography / letter symbols

When a letter is the primary icon, preserve legibility before stylization. Avoid pseudo-font detail that collapses at native size.

## Contrast

UI symbols generally need stronger figure/ground separation than material-rich object sprites.

## Series

Keep stroke/cluster thickness, corner treatment, padding, and visual weight consistent across related symbols.
