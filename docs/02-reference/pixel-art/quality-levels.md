# Pixel Art Quality Levels

Quality is not defined by canvas size alone.

## SIMPLE

Use when a compact icon or symbol only needs:

- recognizable silhouette;
- minimal value separation;
- very small palette;
- no unnecessary material micro-detail.

## STANDARD

Use when the asset needs:

- clear silhouette;
- structured shadow/base/light clusters;
- material distinction;
- identity accents;
- clean alpha and set consistency.

## HIGH DETAIL

Use only when target dimensions and viewing context support:

- additional material transitions;
- richer but controlled palette;
- secondary identity details;
- more nuanced cluster structure.

## Rule

Always choose the lowest level that preserves the requested visual function. Increasing detail after readability is already solved must have a concrete purpose.
