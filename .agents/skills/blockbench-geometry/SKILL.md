# Blockbench Geometry

Use only for active `GEOMETRY` work with `BEDROCK_CUBOID_GEOMETRY` or `GEOMETRY_LOCAL_REPAIR`.

Read only Production Context, Reference Visual, `GEOMETRY.md`, and session state. Execute Primary Form then Structural Detail, preserve approved areas, save the review checkpoint, capture five standard views, run Geometry contract validation, and stop at `GEOMETRY_REVIEW`.

Do not paint, edit UV, use mesh tools, animate, export, or add unrequired geometry. Initial construction may use bounded batches; revisions target one named issue or tightly related pair.
