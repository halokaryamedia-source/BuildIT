Guide Start here
Build with Codex. Review in Blockbench.

BlockIT handles the internal tools and workflow. You only need to provide the reference, target size, geometry method, and whether animation is needed.

1
Prepare the reference

Attach the approved reference image directly in Codex. For visual matching, an image attachment is required; a file path or text description alone is not enough.

2
Start a new model

Copy this template, fill in the blanks, attach the reference image, and send it to Codex.

{{guideTemplate('new_model')}}

Dimensions use Width × Height × Length in Minecraft blocks.

3
Choose the geometry method
DIRECT

Best starting point for most Minecraft-style props and hard-surface models. Codex builds editable Groups and Cubes directly in Blockbench.

3D_ASSISTED

Useful for more complex or organic forms. A 3D reconstruction helps create the starting geometry before Blockbench cleanup.

Not sure which one to use? Ask Codex for a recommendation, then choose the method you want.

4
Review the result in Blockbench

When Codex asks for review, inspect the model here. If it looks correct, reply Continue. If something is wrong, describe the change in normal language.

Approve Continue
Revise The top is too wide. Make it narrower.
5
Follow the simple review flow
Geometry chevron_right UV chevron_right Texture chevron_right Animation* chevron_right Final

Geometry, Texture, and Animation require your visual review. UV is handled between Geometry and Texture and does not need a separate user review. Animation is skipped when it is not required.
