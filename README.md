# BlockIT

BlockIT is a lightweight local desktop bridge that helps users prepare and launch the Blockbench MCP workspace from one place.

It is not a modeling engine and does not implement any Blockbench modeling logic.

## Current status
- Synced locally from `V1` branch in `https://github.com/halokaryamedia-source/BuildIT`.

## Repository goals
- One active MCP bridge engine only.
- Start and monitor `ollmcp` with the official command.
- Prepare Codex MCP configuration safely.
- Detect and select local Blockbench MCP endpoints.
- Show logs and diagnostics, without replacing official MCP behavior.
