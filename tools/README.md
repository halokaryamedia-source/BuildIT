# Tools

Utilities for contract checks and configuration generation.
- `verify-source-contract.ts`: guardrails for source-contract, forbidden paths, and model logic boundaries.
- `verify-app-launcher.ts`: artifact presence check for app-launcher and required UI surface markers.
- `generate-codex-config.ts`: helper to output official BlockIT Codex MCP config examples.
- `check-environment.ps1` / `check-environment.sh`: local environment placeholders.
