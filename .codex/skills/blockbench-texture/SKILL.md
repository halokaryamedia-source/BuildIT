# Blockbench Texture

Use only with `BEDROCK_CUBOID_TEXTURE` or `TEXTURE_LOCAL_REPAIR`. Read Production Context, Reference Visual, `GEOMETRY.md`, `TEXTURING.md`, and state. Execute UV, Base Texture, Detail Texture, direct atlas evidence, review views, validation, then stop at `TEXTURE_REVIEW`.

No PBR, mesh UV, gradients, Geometry redesign, Animation, or final export.
